01

先用深度学习，把量子计算翻译一遍

你不需要重学量子力学。这个项目里用到的量子概念，每一个都能在神经网络里找到对应物——整个量子电路就是一个 可微的、PyTorch 里的前向层。

你熟悉的深度学习这个项目里的量子对应物
神经元 / 特征标量 Qubit（量子比特）：状态是球面上的一个单位向量（Bloch 球）。它不是 0/1 开关，而是"可连续转动的指针"——和一个连续取值的激活值一样可以携带信息。
带权重的线性变换，权重 w 可训练 旋转门 RX/RY/RZ(θ)：把 qubit 的状态向量绕轴转一个角度，θ 就是可训练参数，等价于线性层的权重，由 Adam 更新。
层间特征交互 / 混合（如 attention 里 token 互相加权） CNOT 纠缠门：让一个 qubit 的状态受另一个控制，qubit 之间产生耦合——这是量子版的"特征交互"。
tanh / sigmoid：把输出限幅到有界区间 测量 Pauli-Z 期望值 ⟨Z⟩：电路跑完读出来的数，值域严格在 [−1, 1]——天然就是一个 tanh 式的有界读出。
堆叠多层网络提升表达力 电路深度 + data re-uploading：同一份数据在多个层位反复编码进电路（类似数据反复过多个可训练块），浅电路也能表达复杂函数。
前向 + 反向传播 PennyLane：量子电路对 θ 可微，直接挂进 PyTorch 计算图，loss.backward() 照常工作。

一个 qubit 干的事，一句话：

输入一个角度 x（来自数据）→ 旋转门把指针转上去 → 可训练旋转门 RY(θ) 再转一下 → 和别的 qubit 纠缠 → 最后测量指针在 Z 轴上的投影，读出一个 [−1,1] 的数。

4 个 qubit = 4 个这样的指针并行，读出最多 4 个数。这正好对应一个 4 维的瓶颈表示。

不是用量子网络替代整个模型，而是在经典 FCN 骨干提完特征后，把「算注意力权重」这一小段工作交给量子电路。点下面按钮切换两个训练阶段，看数据流的变化：

PHASE 1  量子分支被 γ=0 门控关闭，残差路径只剩 out = LN(x)，模型严格等价于纯 FCN。此时正常训练卷积骨干 40–60 个 epoch（Adam, lr=1e-3），让特征提取先学到位。

PHASE 2  打开量子分支训 20 个 epoch。γ 从 0 开始慢慢长大，量子贡献从"无"平滑引入；骨干网络用 1/100 的学习率（1e-5）微冻配合，量子分支和分类头正常学习（1e-3）。

03

量子电路内部长什么样

以 Q/K 电路为例（4 qubit）。数据通过旋转门编码进去，可训练旋转门组成 ansatz（量子版"网络层"），CNOT 环负责纠缠，最后测量 Pauli-Z 读出：

数据门 RX/RY（角度 = 输入特征，无可训练参数） 可训练门 RX/RY(θ)（θ 由 Adam 学习） 虚线仪表 = V 电路在此测量全部 4 个 qubit

Q / K 电路

编码 3 轮（RX+RY+CNOT 环）再补一层 RX；ansatz 16 个 θ；只测 q0 的 Pauli-Z，各读出 1 个标量。

V 电路

编码单层 RX+RY+RZ；ansatz 更宽（24 个 θ）；4 个 qubit 全测，读出 4 维向量——V 携带被聚合的内容。

量子参数总账

16 (Q) + 16 (K) + 24 (V)
= 56 电路参数
+ τ / enc_q / enc_v 3 个标量
= 59 个量子参数

投影层 Linear(128→4) / Linear(4→128) 是经典线性层（516 + 640 参数）；输入角度还要过 tanh·π 限幅到 [−π, π]，并乘可学习缩放系数 enc_q / enc_v。

04

注意力权重是怎么算出来的

和标准 self-attention 一模一样的三步，只是 Q/K/V 从"线性层输出"换成"量子电路测量值"：

# 每个时间步 i：量子电路读出（v1 版本）
q_i = QCircuit(x_i) ∈ [−1,1]　　k_i = KCircuit(x_i) ∈ [−1,1]　　v_i = VCircuit(x_i) ∈ [−1,1]⁴
# 和经典 attention 同构：打分 → softmax → 加权求和
s_ij = softmax_j( τ · q_i · k_j )　　　　out_i = Σ_j s_ij · v_j
# 投回 128 维，残差加回（γ 是门控标量）
h = LayerNorm( γ · Linear₄→₁₂₈(out) + x )

和经典 attention 的对应关系

经典：Linear 投影出 Q/K/V 向量，点积衡量 token 相似度量子：电路把 4 维特征演化后测量出 Q/K/V，量子态演化 + 纠缠替代了矩阵乘法
经典：softmax(QKᵀ/√d)量子：公式相同，多一个可学习温度 τ
经典：残差 + LayerNorm量子：完全保留，外加 γ 零初始化门控

v1 的已知短板（v2 已修）

v1 的 Q、K 各只读 1 个标量，注意力矩阵是"标量×标量"的低秩打分，更像全局时间重加权器而非真正的多头注意力。

v2（MHQSA）改为：Q/K/V 都测 4 维向量 + 2 个注意力头 + 两层 data re-uploading，量子参数 59 → 72，成为真正意义上的向量点积注意力。

另有 QCEA 变体：不做时间注意力，而是在 GAP 后的 128 维通道向量上过量子电路，用 2·sigmoid(·) 生成近恒等的通道乘性门——量子版 SE，在多变量数据集上提升最大（RacketSports +3.95 pp）。

05

两阶段训练：三个病，三副药

直接把随机初始化的量子分支插进训练好的网络，精度会崩。实验中定位了三个具体病因，每个都有对应的结构/训练手段：

病 1：阶段转换休克

骨干已学好特征，Phase 2 突然接入随机量子分支，其输出是纯噪声，残差一加直接覆盖好特征，分类头崩溃。

药：γ 零初始化门控

out = LN(γ·量子(x) + x)，γ 初值 = 0 → 量子分支初始贡献严格为 0，模型起点就是纯经典 FCN，γ 训练中慢慢长大，量子只做"加分项"。ResNet 式零初始化思路。

病 2：注意力坍缩

测量值锁死在 [−1,1]，标量点积 logits 只有 [−2,2]，在 softmax 眼里太小 → 权重接近均匀分布，退化成平均池化，时间特征被抹平。

药：可学习温度 τ（初值 5.0）

softmax(τ·qk/√d)，τ 放大 logits 让注意力能变尖峰。拖下面的滑块直观感受 ↓

病 3：冻结骨干不配合

硬冻结卷积层后，特征分布是朝"没有量子层"优化的，大量值饱和在 tanh 边缘，量子电路吃不到合适输入。

药：差分学习率微调

不硬冻结：骨干 lr=1e-5（1/100，保护已学特征又允许迎合量子输入），量子分支 + 分类头 lr=1e-3。
